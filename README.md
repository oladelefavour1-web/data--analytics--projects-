# AfriMart KollyBright Sales Dashboard
This is a data analytics project that analyses sales performance for AfriMart KollyBright across African countries.
## Project  Overview
-**Total Revenue** : 10 billion
-**Total Profit**: 2 billion
-**Total units sold** : 1 million
## key insights
- Nigeria generated the highest revenue
- Rice (50kg bag) is the top performing product by profit
- Sales are tracked across multiple African countries (Nigeria, Tanzania, Cot d'Ivoire, Kenya, Rwanda, Ghana, Uganda, Egypt)
