ZoomRide SQL Project

Project Overview

This project involves analysing and cleaning the ZoomRide trip database using MySQL.

SQL Tasks Completed

- Q1: Total Trips
- Q2: 5 Longest Completed Trips
- Q3: Trips by City
- Q4a: Identifying Duplicate Trips
- Q4b: Identifying Completed Trips with Missing Fare
- Q5: Data Cleaning
- Q5b: Verification of Trips by City
- Q5c: Verification of Total Rows
- Q6: Revenue by City
- Q7: Revenue by Month
- Q8: Revenue by Vehicle Type
- Q9: Customers Who Never Booked a Trip
- Q10: Top 3 Customers by Total Spend

Tools Used

- MySQL
- SQL

Key Skills Demonstrated

- Data cleaning
- Filtering and sorting
- Aggregation
- GROUP BY and HAVING
- JOINs
- Subqueries
- Date functions
- Revenue analysis
